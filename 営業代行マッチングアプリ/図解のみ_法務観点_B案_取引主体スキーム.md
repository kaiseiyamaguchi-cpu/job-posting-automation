## 図1：全体構造（契約/フロー/金流まとめ）

```
┌──────────────────────────────────────────────────────────────┐
│                    全体：B案（鬼カナ＝取引主体/MoR）          │
└──────────────────────────────────────────────────────────────┘

【① 契約（当事者）】

  企業（買い手）                  鬼カナ（取引主体/MoR）                 営業顧問（外注先）
       │      契約A：役務提供契約         │          契約B：業務委託契約          │
       ├───────────────────────────────▶│◀─────────────────────────────────────┤
       │   対価支払い（役務対価）         │          委託費支払い（外注費）        │
       └───────────────────────────────▶│─────────────────────────────────────▶│

【② アプリ利用フロー（入口2つ）】

  [入口A：案件募集→応募]                      [入口B：スカウト→承諾]
   企業：案件募集作成                           企業：顧問検索→スカウト
          │                                            │
          ▼                                            ▼
   顧問：案件検索→応募                          顧問：承諾/辞退
          │                                            │
          └──────────────┬───────────────┬───────────────┘
                         ▼               ▼
                   双方合意（マッチング成立）
                         ▼
                 チャット（要件すり合わせ）
                         ▼
                 日程調整（候補→確定）
                         ▼
                 企業→鬼カナへ支払い
                 （振込/カード）
                         ▼
                     商談実施
                         ▼
            48h 異議申立期間（異議なし＝自動確定）
                         ▼
               確定：鬼カナ→顧問へ委託費支払い

【③ お金の流れ（80/20・返金）】

  企業 ──(役務対価: 例 5万円)──▶ 鬼カナ
                     ├─ 売上（20%相当: 例 1万円）
                     └─ 委託費（80%相当: 例 4万円）──▶ 顧問

  無効（異議成立）の場合：
  鬼カナ ──(返金)──▶ 企業
  顧問は 不支給 / 相殺 / 返還（契約Bで規定）
```

## 図2：契約構造（二段構え：契約A/契約B）

```
          ┌───────────────────────────┐
          │        契約A（役務提供）   │
          │   企業  ⇄  鬼カナ（MoR）   │
          └───────────────────────────┘
                 ▲                 │
                 │  役務提供        │ 対価支払い
                 │（募集/スカウト/  │（鬼カナへ）
                 │ チャット/日程/裁定）
                 │                 ▼

          ┌───────────────────────────┐
          │        契約B（業務委託）   │
          │   鬼カナ（MoR） ⇄ 顧問     │
          └───────────────────────────┘
                 ▲                 │
                 │  業務提供        │ 委託費支払い
                 │（アポ獲得/営業活動）│（鬼カナ→顧問）
                 │                 ▼

ポイント：
- 「企業→顧問への送金」を“鬼カナが中継”ではなく、
  「企業→鬼カナ（役務対価）」＋「鬼カナ→顧問（外注費）」に寄せる。
```

## 図5：3者の関与（時系列イメージ）

```
時間 →

[登録]
  企業 ──(契約A同意/会社情報)──▶ 鬼カナ
  顧問 ──(契約B同意/支払先情報)──▶ 鬼カナ

[マッチング]
  企業 ⇄（案件募集/スカウト）⇄ 鬼カナ ⇄（応募/承諾）⇄ 顧問

[コミュニケーション]
  企業 ⇄（チャット）⇄ 顧問
        （日程候補）→ 鬼カナ →（共有）→ 顧問
        （回答）← 鬼カナ ←（回答）← 顧問

[支払い〜確定]
  企業 ──(支払い)──▶ 鬼カナ
  48h：異議なし → 自動確定
  鬼カナ ──(委託費)──▶ 顧問

[異議あり]
  企業 ──(異議申立/証拠)──▶ 鬼カナ ──(裁定)──▶ 企業/顧問
  無効：鬼カナ→企業へ返金 / 顧問は不支給 or 相殺・返還
```

## 図6：お金の流れ（80/20・返金・相殺の位置）

```
（通常：成立）

  企業
   │  役務対価（例：50,000円）
   ▼
  鬼カナ（取引主体/MoR）
   ├─ 売上（20%相当：10,000円）
   └─ 外注費/委託費（80%相当：40,000円） ─────▶ 顧問

（無効：返金）

  鬼カナ ─────▶ 企業（返金）
  顧問：
   - 未払いなら「不支給」
   - 既払い/仮払いがあるなら「返還」または「次回相殺」
     （契約Bで条件・手続きを固定）
```
