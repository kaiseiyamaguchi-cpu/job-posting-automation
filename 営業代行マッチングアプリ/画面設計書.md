```css
/* Primary */

--primary-700: #1d4ed8

/* Background */
--bg-primary: #0f172a    /* ダーク背景 */

--bg-card: #334155

/* Text */
--text-primary: #f1f5f9
--text-secondary: #cbd5e1
--text-muted: #94a3b8

/* Success */
--success: #10b981

/* Warning */
--warning: #f59e0b

/* Danger */
--danger: #ef4444
```

### タイポグラフィ
- フォント: Inter（英数字）、Noto Sans JP（日本語）
- 見出し: 24px - 32px
- 本文: 14px - 16px
- 小文字: 12px - 14px
