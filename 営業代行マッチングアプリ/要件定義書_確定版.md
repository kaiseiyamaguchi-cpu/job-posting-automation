## 🎯 プロジェクト概要

### ビジネス課題
鬼ニカナ社は営業代行と企業のマッチング業務を手動で行っており、業務効率化が急務。

### 解決策
営業代行を探す企業と営業代行パートナーをつなぐマッチングプラットフォームを構築。

### ユーザー種別
1. **企業**：営業代行を検索・申請・メッセージでやり取り
2. **営業代行**：申請を承認・メッセージでやり取り
3. **管理者**：全体管理・監視

## ✅ MVPスコープ（確定版）

### 実装する機能

#### 1. 認証機能
- メール + パスワードログイン
- 新規登録（ユーザー種別選択：企業/営業代行）
- ログアウト

#### 2. 営業代行検索機能（企業側）
- 営業代行一覧表示
- 検索・フィルタリング
  - 業種
  - エリア
  - キーワード検索
- 営業代行詳細プロフィール表示
- 「マッチング申請」ボタン

#### 3. マッチング申請機能
- 申請作成（企業 → 営業代行）
  - 月予算
  - 依頼内容
  - 提案期限
- 申請一覧表示
  - 企業側：送信した申請の状態確認
  - 営業代行側：受信した申請の承認/却下
- ステータス管理
  - pending（申請中）
  - approved（承認済み）
  - rejected（却下）

#### 4. 1対1メッセージ機能
- メッセージスレッド
  - 承認されたマッチングのみメッセージ可能
  - スレッド一覧（未読件数表示）
- チャット画面
  - リアルタイム更新（Supabase Realtime）
  - メッセージ送受信
  - 既読管理

#### 5. ダッシュボード
- **企業向け**
  - 申請中の件数
  - 承認済みの件数
  - 未読メッセージ数
  - 次のアクション
- **営業代行向け**
  - 新着申請数
  - 対応中企業数
  - 未読メッセージ数
- **管理者向け**
  - 総ユーザー数
  - 総申請数
  - 承認率
  - アクティブスレッド数

#### 6. プロフィール管理
- **企業**
  - 会社名、業種、エリア、依頼内容、担当者名、電話番号
- **営業代行**
  - 名前、得意分野（複数選択）、対応エリア（複数選択）、自己PR、電話番号

#### 7. 管理者機能
- ユーザー一覧（企業・営業代行）
- マッチング申請一覧
- メッセージスレッド監視
- 基本的な検索・ソート

## 🔄 ユーザーフロー

### 企業側フロー
```
1. 新規登録（ユーザー種別：企業）
2. 企業プロフィール入力
3. ログイン
4. 営業代行を検索
5. 営業代行詳細プロフィール閲覧
6. 「マッチング申請」ボタンをクリック
7. 申請内容を入力
   - 月予算
   - 依頼内容
   - 提案期限
8. 申請送信（ステータス: pending）
   ↓
9. 営業代行が承認
   ↓
10. メッセージスレッドが自動作成
11. チャットでやり取り
```

### 営業代行側フロー
```
1. 新規登録（ユーザー種別：営業代行）
2. 営業代行プロフィール入力
3. ログイン
4. ダッシュボードで「新着申請」を確認
5. 申請一覧で内容確認
6. 承認 or 却下
   ↓ 承認した場合
7. メッセージスレッドが自動作成
8. 企業とチャットでやり取り
```

### 管理者側フロー
```
1. ログイン（ユーザー種別：管理者）
2. 管理者ダッシュボードで全体統計確認
3. ユーザー管理
   - 企業一覧
   - 営業代行一覧
4. マッチング申請管理
   - 全申請の状態確認
5. メッセージスレッド監視
   - 会話履歴の確認
```
