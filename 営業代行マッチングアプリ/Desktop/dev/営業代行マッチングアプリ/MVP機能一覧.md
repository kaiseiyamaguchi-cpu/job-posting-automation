# 営業代行マッチングアプリ MVP 機能一覧

## 共通機能
- メール + パスワードによるログイン／ログアウト
- ユーザー種別（企業・営業代行・管理者）に応じた画面遷移とアクセス制御
- 1対1メッセージ機能（スレッド一覧、未読件数、チャット画面、送受信）
- ダッシュボードでの進行中案件・未読・次アクション確認
- 外部カレンダーAPI連携（Google Calendar / TimeRex等）による日程確定・更新

## 企業向け機能
- 担当営業代行とのチャットスレッド一覧と履歴閲覧
- 面談候補日の作成・送信（API連携で空き枠読み込み / 提案）
- 面談確定状況のタイムライン表示（承認済み・再提案待ち・確定）
- Google Meet等オンライン会議URLの自動取得・共有
- 自社プロフィール（基本情報・依頼内容）の編集

## 営業代行向け機能
- 企業からの面談候補受信・承認 / 再提案
- 自分の空き時間テンプレート設定とAPI同期
- 確定済みスケジュール一覧（カレンダー / リスト表示）
- 面談前後のフォロー用チャット送受信
- 営業代行プロフィール（得意分野・対応エリア・自己PR）の編集と公開プレビュー

## 管理者向け機能
- 営業代行アカウント一覧（基本情報・得意領域・予定数・稼働状況）
- 企業アカウント一覧（業種・担当者・進行中スケジュール数）
- 面談スケジュール監視（営業代行 × 企業 × 最新会話ログ × ステータス）
- 連絡履歴メモやフォローフラグ（要停止・要フォロー等）の登録・更新
- 各テーブルの検索・フィルタ・ソート（会社名、更新日時、ステータスなど）

## MVPスコープ外（フェーズ2以降）
- 自動マッチング / 営業代行検索・推薦機能
- SMS 認証および企業書類アップロードによる審査
- ファイル添付・高度な通知（メール / プッシュ / Slack 等）
- 決済、評価・レビュー、AI マッチングなどの拡張機能
