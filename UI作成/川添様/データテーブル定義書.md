## **詳細定義**

### **1. users（ユーザー基本情報）**

**コレクション名**: `users`

Firebase Authenticationと連携するユーザー情報コレクション。ドキュメントIDはFirebase Auth UIDと同じ値を使用。

| フィールド名 | Flutter Flow型 | Firestore型 | 必須 | 説明 |
| --- | --- | --- | --- | --- |
| email | String | string | ○ | メールアドレス |
| nickname | String | string | ○ | ニックネーム（表示名） |
| avatar_url | Image Path | string | - | プロフィール画像URL（現在は使用せず、デフォルトアイコンを使用） |
| bio | String | string | - | 自己紹介文（最大200文字） |
| role | String | string | ○ | ロール（user / admin）デフォルト: user |
| is_studying | Boolean | boolean | ○ | 現在学習中かどうか デフォルト: false |
| is_suspended | Boolean | boolean | ○ | アカウント停止フラグ デフォルト: false |
| suspended_at | Timestamp | timestamp | - | アカウント停止日時 |
| last_login_at | Timestamp | timestamp | - | 最終ログイン日時 |
| created_at | Timestamp | timestamp | ○ | アカウント作成日時 |
| updated_at | Timestamp | timestamp | ○ | 更新日時 |

**インデックス**:
- `email` (ASC)
- `role` (ASC)
- `is_suspended` (ASC)

**Flutter Flow設定**:
- Collection Path: `users`
- Document ID Source: Firebase Auth UID
- Enable Offline Persistence: Yes

### **2. projects（学習プロジェクト）**

**コレクション名**: `projects`

ユーザーの学習プロジェクト情報。Freeプランは1つ、Proプランは複数作成可能。

| フィールド名 | Flutter Flow型 | Firestore型 | 必須 | 説明 |
| --- | --- | --- | --- | --- |
| user | Document Reference | reference | ○ | ユーザー参照（users コレクション） |
| title | String | string | ○ | プロジェクト名 |
| total_pages | Integer | integer | ○ | 総ページ数（整数、変更不可） |
| pages_completed | Integer | integer | ○ | 完了ページ数 デフォルト: 0 |
| start_date | Timestamp | timestamp | ○ | 開始日 |
| end_date | Timestamp | timestamp | ○ | 終了予定日（変更可能） |
| weekdays | List\<Integer\> | array | ○ | 学習曜日 [1,3,5] = 月水金 (1=月, 7=日) |
| wake_time | String | string | ○ | 起床時間 "06:00" 形式 |
| awarded_progress_bonuses | List\<Integer\> | array | ○ | 付与済み進捗率ボーナス [30, 50, 70, 100] デフォルト: [] |
| is_archived | Boolean | boolean | ○ | アーカイブ済みフラグ デフォルト: false |
| created_at | Timestamp | timestamp | ○ | 作成日時 |
| updated_at | Timestamp | timestamp | ○ | 更新日時 |

**インデックス**:
- `user` (ASC)
- `user` (ASC) + `is_archived` (ASC) (複合)

**Flutter Flow設定**:
- Collection Path: `projects`
- Document ID: Auto-generated
- Reference Field: `user` → `users` collection
- Query Filter: user == Authenticated User Reference

**注意事項**:
- `total_pages` は作成後変更不可（進捗率ボーナスの整合性のため）
- `end_date` のみ変更可能
- 削除は物理削除

### **3. sessions（学習セッション履歴）**

**コレクション名**: `sessions`

各学習セッションの開始・終了記録。

| フィールド名 | Flutter Flow型 | Firestore型 | 必須 | 説明 |
| --- | --- | --- | --- | --- |
| user | Document Reference | reference | ○ | ユーザー参照（users コレクション） |
| project | Document Reference | reference | ○ | プロジェクト参照（projects コレクション） |
| started_at | Timestamp | timestamp | ○ | 学習開始日時 |
| ended_at | Timestamp | timestamp | - | 学習終了日時（学習中はnull） |
| duration | Integer | integer | - | 学習時間（秒）、24時間=86400秒を上限とする |
| session_date | String | string | ○ | セッション日付 "2025-01-01" 形式（学習開始時刻基準） |
| pages_studied | Integer | integer | - | このセッションで学習したページ数（学習終了時に入力） |
| status | String | string | ○ | ステータス（studying / completed） デフォルト: studying |
| created_at | Timestamp | timestamp | ○ | 作成日時 |
| updated_at | Timestamp | timestamp | ○ | 更新日時 |

**インデックス**:
- `user` (ASC) + `session_date` (ASC) (複合)
- `user` (ASC) + `status` (ASC) (複合)
- `project` (ASC)

**Flutter Flow設定**:
- Collection Path: `sessions`
- Document ID: Auto-generated
- Reference Fields: 
  - `user` → `users` collection
  - `project` → `projects` collection
- Query Filter: user == Authenticated User Reference

**24時間ルール**:
- 学習終了時に `ended_at - started_at` が24時間（86400秒）を超える場合、`duration` を86400に制限
- `ended_at` は実際の終了時刻を保存

### **4. learning_records（日次学習記録）**

**コレクション名**: `learning_records`

1日（学習開始時刻基準）あたりの学習記録とポイント計算の基礎データ。

| フィールド名 | Flutter Flow型 | Firestore型 | 必須 | 説明 |
| --- | --- | --- | --- | --- |
| user | Document Reference | reference | ○ | ユーザー参照（users コレクション） |
| project | Document Reference | reference | ○ | プロジェクト参照（projects コレクション） |
| learning_date | String | string | ○ | 学習日 "2025-01-01" 形式（学習開始時刻基準） |
| first_session_start | Timestamp | timestamp | ○ | その日の最初のセッション開始時刻 |
| total_duration | Integer | integer | ○ | その日の全セッションの合計時間（秒） |
| pages_studied | Integer | integer | ○ | その日に学習したページ数（整数） |
| wake_success | Boolean | boolean | ○ | 起床成功フラグ（起床時間より前に開始したか） |
| has_completed_session | Boolean | boolean | ○ | 学習実施フラグ（開始→終了を完了したか） |
| created_at | Timestamp | timestamp | ○ | 作成日時 |
| updated_at | Timestamp | timestamp | ○ | 更新日時 |

**インデックス**:
- `user` (ASC) + `learning_date` (ASC) (複合、unique)
- `project` (ASC) + `learning_date` (ASC) (複合)
- `learning_date` (ASC)

**Flutter Flow設定**:
- Collection Path: `learning_records`
- Document ID: Auto-generated or Composite (`{user_id}_{learning_date}`)
- Reference Fields:
  - `user` → `users` collection
  - `project` → `projects` collection
- Query Filter: user == Authenticated User Reference

**ポイント計算について**:
- このコレクションからポイントを動的に計算し、`user_points` コレクションに集計

### **5. user_points（ユーザーポイント管理）**

**コレクション名**: `user_points`

ユーザーごとの累積ポイントを管理。ランキング計算の基礎。

| フィールド名 | Flutter Flow型 | Firestore型 | 必須 | 説明 |
| --- | --- | --- | --- | --- |
| user | Document Reference | reference | ○ | ユーザー参照（users コレクション、unique） |
| total_points | Double | double | ○ | 累積ポイント（全期間） デフォルト: 0 |
| monthly_points | JSON | map | ○ | 月別ポイント {"2025-01": 150, "2025-02": 200} |
| yearly_points | JSON | map | ○ | 年別ポイント {"2025": 1500} |
| wake_success_count | Integer | integer | ○ | 起床成功回数（全期間） デフォルト: 0 |
| learning_days_count | Integer | integer | ○ | 学習実施日数（全期間） デフォルト: 0 |
| pages_total | Integer | integer | ○ | 累計学習ページ数 デフォルト: 0 |
| progress_bonus_total | Integer | integer | ○ | 進捗率ボーナス合計ポイント デフォルト: 0 |
| updated_at | Timestamp | timestamp | ○ | 更新日時 |

**インデックス**:
- `user` (ASC)
- `total_points` (DESC)

**Flutter Flow設定**:
- Collection Path: `user_points`
- Document ID: Same as User UID (1対1関係)
- Reference Field: `user` → `users` collection
- Query Filter: user == Authenticated User Reference

**更新タイミング**:
- 学習セッション終了時にリアルタイム更新
- 進捗率ボーナス取得時に加算

**ポイント計算式**:
```
total_points = 
  (wake_success_count × 10) +
  (learning_days_count × 5.5) +
  (pages_total × 0.1) +
  progress_bonus_total
```

### **7. rankings（現在のランキング）**

**コレクション名**: `rankings`

| フィールド名 | Flutter Flow型 | Firestore型 | 必須 | 説明 |
| --- | --- | --- | --- | --- |

| period_key | String | string | ○ | 期間キー "2025-01" or "2025" |
| rank | Integer | integer | ○ | 順位（同率順位の場合は同じ値） |
| total_score | Double | double | ○ | 合計スコア |
| nickname | String | string | ○ | ニックネーム（非正規化、表示用） |
| avatar_url | Image Path | string | - | プロフィール画像URL（非正規化、表示用） |
| updated_at | Timestamp | timestamp | ○ | 更新日時 |

**インデックス**:
- `period_type` (ASC) + `period_key` (ASC) + `total_score` (DESC) (複合)

- Collection Path: `rankings`
- Document ID: Auto-generated or Composite (`{user_id}_{period_type}_{period_key}`)
- Reference Field: `user` → `users` collection

**更新タイミング**:
- ユーザーがポイントを獲得するたびにリアルタイム更新
- ランキング画面を開いた時点の順位を表示

**同率順位**:
- 例: 10位が3人いる場合、全員10として保存、次は13位

## **リレーションシップ図（Document Reference）**

```
users (1) ─── (N) projects [user]
users (1) ─── (N) sessions [user]
users (1) ─── (N) learning_records [user]
users (1) ─── (1) user_points [user]
users (1) ─── (1) streaks [user]
users (1) ─── (N) rankings [user]
users (1) ─── (N) ranking_history [user]
users (1) ─── (N) community_messages [user]
users (1) ─── (N) reports [reporter]
users (1) ─── (N) reports [reported_user]
users (1) ─── (1) subscriptions [user]

projects (1) ─── (N) sessions [project]
projects (1) ─── (N) learning_records [project]

community_messages (1) ─── (N) reports [message]
```

**Flutter Flow での参照方法**:
- 各コレクションは Document Reference フィールドで他のドキュメントを参照
- 例: `projects` コレクションの `user` フィールドは `users` コレクションへの参照
- Flutter Flow UI では「Reference」型として設定し、参照先コレクションを指定

## **ポイント計算ロジック**

### **学習終了時の処理フロー**

1. **セッション終了**:
   - `sessions.ended_at` を記録
   - `sessions.duration` を計算（24時間超の場合は86400秒に制限）
   - `sessions.pages_studied` を記録
   - `sessions.status` を `completed` に更新

2. **learning_records の更新/作成**:

## **補足事項**

### **Flutter Flow + Firestore の特性**

#### **Document ID の扱い**
- Firestoreでは各ドキュメントに自動生成される一意のIDがある
- Flutter Flowでは明示的に `id` フィールドを定義する必要はない
- ドキュメントIDは `Document Reference` として自動的に管理される

#### **Document Reference の利点**
- 型安全な参照が可能
- Flutter Flowのビジュアルエディタで参照先のデータに簡単にアクセス可能
- `user.nickname` のようにドット記法で参照先フィールドにアクセス
- ネストされたクエリやJOINが不要

#### **インデックスの作成**
- Firestoreでは複合クエリを実行する場合、事前にインデックスを作成する必要がある
- Flutter Flowからクエリを実行すると、必要なインデックスを自動的に提案してくれる
- 本ドキュメントに記載されたインデックスは、Firebase Console から手動で作成可能

### **非正規化の理由**
- `rankings`, `ranking_history`, `community_messages` でユーザー情報を非正規化
- これにより、ランキング表示やコミュニティ表示時に都度 `users` コレクションを参照する必要がなく、パフォーマンスが向上
- Flutter Flowでは参照先データの取得が容易だが、大量データの表示時はパフォーマンス向上のため非正規化を採用

### **Firestoreセキュリティルール**
Flutter Flowで実装する際、以下のセキュリティルールを Firestore Security Rules に設定：

```javascript
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    // ユーザー自身のドキュメントのみ読み書き可能
    match /users/{userId} {
      allow read: if request.auth != null;
      allow write: if request.auth != null && request.auth.uid == userId;
    }
    
    // プロジェクトは自分のもののみ
    match /projects/{projectId} {
      allow read, write: if request.auth != null && 
        resource.data.user == /databases/$(database)/documents/users/$(request.auth.uid);
    }
    
    // セッション・学習記録も同様
    match /sessions/{sessionId} {
      allow read, write: if request.auth != null && 
        resource.data.user == /databases/$(database)/documents/users/$(request.auth.uid);
    }
    
    match /learning_records/{recordId} {
      allow read, write: if request.auth != null && 
        resource.data.user == /databases/$(database)/documents/users/$(request.auth.uid);
    }
    
    // ランキングは全員読み取り可能
    match /rankings/{rankingId} {
      allow read: if request.auth != null;
      allow write: if false; // Cloud Functionsからのみ更新
    }
    
    // コミュニティは全員読み取り、ログインユーザーは書き込み可能
    match /community_messages/{messageId} {
      allow read: if request.auth != null;
      allow create: if request.auth != null;
      allow update, delete: if request.auth != null && 
        (resource.data.user == /databases/$(database)/documents/users/$(request.auth.uid) ||
         get(/databases/$(database)/documents/users/$(request.auth.uid)).data.role == 'admin');
    }
    
    // 広告は全員読み取り、管理者のみ書き込み
    match /announcements/{announcementId} {
      allow read: if request.auth != null;
      allow write: if request.auth != null && 
        get(/databases/$(database)/documents/users/$(request.auth.uid)).data.role == 'admin';
    }
  }
}
```

### **Flutter Flow での実装Tips**

1. **Authenticated User の活用**
   - Flutter Flowではログインユーザーをグローバルステートとして利用可能
   - クエリフィルタで `user == Authenticated User Reference` を使用

2. **リアルタイム更新**
   - Firestoreはリアルタイムリスナーをサポート
   - Flutter Flowで「Listen for Changes」を有効化すると自動的にUIが更新される

3. **バッチ処理**
   - 月次バッチ処理（ランキング確定等）は Firebase Cloud Functions で実装
   - Firebase Scheduledを使用して定期実行

4. **トランザクション**
   - ポイント加算などの整合性が重要な処理は Cloud Functions でトランザクションを使用
   - Flutter Flowから Cloud Functionsを呼び出す
