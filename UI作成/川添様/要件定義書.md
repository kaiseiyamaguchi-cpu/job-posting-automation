## **1. プロジェクト概要**

| 項目 | 内容 |
| --- | --- |
| プロダクト名 | TSUZUKU（継続を称える学習管理＆コミュニティアプリ） |
| 目的 | 起床時間・学習記録を可視化し、ランキングやコミュニティで継続意欲を高める |
| 開発/運用環境 | フロント: Flutter Flow（スマートフォンWeb）、バックエンド: Firebase（Auth / Firestore / Storage / Realtime DB） |
| 決済 | Stripe（日本円、クレカ/デビット対応） |
| リリース計画 | 3ヶ月（1ヶ月: 要件定義、2ヶ月: 構築） |

### **1.1 ターゲットユーザー**

- 早起きや朝学習を習慣化したい社会人・学生
- 学習仲間と励ましあえるコミュニティを求める人
- 自己管理・ランキングがモチベーションになる人

### **1.2 ステークホルダー**

- プロダクトオーナー: 川添様
- 開発/デザイン: Flutter Flow制作チーム
- 決済・法務: Stripe / 弁護士確認済（景品表示法の留意点あり）

## **2. ユースケースとフロー（要約）**

### **2.1 代表的な利用シナリオ**

1. **朝の学習開始**: 起床 → アプリ起動 → ホームで今日の予定確認 → 「開始」 → 学習 → 「終了」でページ数入力 → ポイント付与 → 進捗更新
2. **学習進捗管理**: プロジェクト設定（教科書名/総ページ/期間/曜日/起床時間）→ 日々の記録 → ホーム/プロフィールで進捗・ストリーク確認
3. **ランキング確認**: 月間ランキング閲覧（自分の順位/他ユーザー比較）→ 年間ランキング（3〜4月以降）
4. **コミュニティ交流**: 掲示板で質問・励まし → 通報機能で健全性維持
5. **サブスクリプション**: トライアル終了時にProへのアップグレード → 有料機能解放
6. **管理者対応**: 通報レビュー/ユーザー管理 → 必要に応じアカウント停止

## **3. 機能要件**

### **3.1 認証機能**

- **新規登録**: メール・パスワード・ニックネーム・利用規約同意（形式/重複チェック）
- **ログイン**: メール + パスワード
- **パスワードリセット**: メール送信による再設定（リセットリンク有効期限・再送信回数は無制限）
- **権限**: 一般ユーザー / 管理者（手動でFirebaseから付与）
- **セッション管理**: Firebase Authenticationのデフォルト設定に準拠（自動ログアウト等の特別な制御なし）

### **3.2 ホーム（学習管理）**

- **広告/お知らせエリア**: 画面上部に管理者が作成した広告・お知らせを自動スクロール表示
- **現在学習中ユーザー数**: リアルタイム表示（Usersテーブルの学習中フラグを集計）
- **セッション管理**: 
  - 開始→終了のトグル
  - タイマー表示（学習時間の経過表示）
  - 学習終了時にページ数入力（整数のみ、0以下はエラー、プロジェクトの総ページ数が上限）
  - **24時間ルール**: 学習開始から24時間経過で自動的に学習終了扱い
- **ストリーク表示**: 連続学習日数の表示
- **プロジェクトカード**: 
  - プロジェクト名、完了ページ数/総ページ数、達成率
  - 複数プロジェクト対応（Freeプランは1つのみ、Proプランは複数）
  - 編集導線
- **主要CTA**: 学習開始/終了、プロジェクト編集、プロジェクト追加（Pro限定）

### **3.3 プロジェクト/学習設定**

- **設定項目**: 
  - プロジェクト名（必須）
  - 総ページ数（必須、整数）
  - 開始日～終了予定日（必須）
  - 学習曜日（複数選択可能）
  - 起床時間（必須）
- **保存時バリデーション**: 未入力チェック、数値フォーマットチェック
- **編集制限**: 
  - プロジェクト開始後、**期間（終了予定日）の変更は可能**
  - **総ページ数は変更不可**（変更すると進捗率ボーナスの整合性が崩れるため）
- **学習終了時の処理**: 
  - 当日ページ数入力 → 累積完了ページに加算 → 達成率更新
  - **ページ数入力制約**: 入力するページ数は現在の完了ページ数より大きい値のみ許可（減らすことは不可）
  - 進捗率ボーナス判定（30%, 50%, 70%, 100%）
  - **一度付与された進捗率ボーナスは再取得不可**（プロジェクトごとに付与済みボーナスを記録）

### **3.4 ランキング**

- **期間**: 
  - **月間ランキング**（MVP時点で実装）
  - **年間ランキング**（Phase2で実装予定、データ構造は対応しておく）
- **表示**: 
  - TOP20のユーザーを表示
  - 同率順位の場合は同順位表示（例: 10位が3人いた場合、次は13位）
  - 自分の順位を強調表示（TOP20圏外の場合は「圏外」と表示）
- **ポイントルール**：
  - 起床成功1回 = 10点（設定起床時間より前に学習開始した場合）
  - 学習実施1日 = 5.5点（学習開始→終了の流れが完了した場合、1日1回のみ）
  - 消化ページ1ページ = 0.1点
  - 進捗率ボーナス = 30%:30点, 50%:50点, 70%:70点, 100%:100点（各プロジェクトで閾値到達ごと付与、複数プロジェクトで何度でも取得可能）
- **集計タイミング**:
  - 月間ランキング確定: 翌月1日 0:00（日本時間）
  - 途中経過の更新: ランキング画面を開いた時点の順位を表示（準リアルタイム）
  - ポイント加算: リアルタイム加算
- **表示切り替え**: 先月確定順位 / 今月途中経過
- **インセンティブ**: 景品（物品）は売上状況に応じ別途実施（景品表示法: 総額=年間売上2%、個人上限=10万円）

### **3.5 コミュニティ（オープンチャット）**

- **形式**: 単一のオープンチャット（スレッド機能なし）
- **メッセージ表示**: 
  - 時系列順に表示（新しいメッセージが下）
  - 過去100件まで表示
  - それより過去のメッセージを見る場合は「過去のメッセージを読み込む」ボタンをタップ
- **投稿機能**: 
  - テキストのみ（画像・添付ファイルなし）
  - 最大400文字
  - 投稿後の編集・削除は不可
- **表示項目**: 投稿者名、投稿時刻、本文
- **通報機能**: 
  - 各メッセージに通報ボタン
  - 通報理由を入力 → 管理者レビュー
  - 通報されたメッセージも通常通り表示（非表示にはしない）
  - 通報者・被通報者への通知なし

### **3.6 プロフィール & 設定**

- **プロフィール情報**: 
  - デフォルトアイコン（ニックネームの最初の1文字を表示）、表示名、自己紹介
  - ポイント数（現在の累計ポイント）
  - 継続日数（現在のストリーク）
  - 最近の活動ログ
- **学習データ可視化**:
  - **累計学習時間**（全期間、Freeプランも閲覧可能）
  - **学習履歴リスト**（月別の学習日を日付リストで表示、Freeプランも閲覧可能）
  - **当日の学習記録**（最初のセッションの開始時刻、複数セッションの学習時間合計）
  - **月別詳細履歴**（Pro限定、過去の月の詳細な学習履歴）
- **設定**: 
  - 学習設定（§3.3、プロジェクト管理）
  - 退会
  - 利用規約/プライバシーポリシーへのリンク
- **お問い合わせ**: 川添様への連絡（メール想定）

### **3.7 サブスクリプション**

- **モデル**: 
  - 新規登録時に「トライアルを開始する」ボタンで能動的にトライアル開始
  - ボタンを押さない場合はFreeプランのまま
  - トライアル期間: 1ヶ月（Proの全機能が使用可能）
  - トライアル終了時に自動課金（Stripeによる自動更新）
  - 解約後の再課金も可能
  
- **Free vs Pro 機能差分**:

| 機能 | Free | Pro |
| --- | --- | --- |
| 基本的な学習記録 | ○ | ○ |
| プロジェクト数 | 1つのみ | 複数 |
| 月間・年間ランキング閲覧 | ○ | ○ |
| コミュニティ参加 | ○ | ○ |
| 累計学習時間表示 | ○ | ○ |
| 学習履歴リスト（当月） | ○ | ○ |
| 月別詳細履歴（過去の月） | × | ○ |

- **課金画面**: 
  - プラン比較表（Free/Pro）
  - FAQ
  - CTA「今すぐアップグレード」または「トライアルを開始」
  
- **Stripe決済実装**: Stripe CheckoutまたはStripe Elements（実装が容易な方を選択）

- **課金失敗時の処理**: Stripeのデフォルトリトライ機能に準拠

### **3.8 管理者機能**

- **管理者ログイン**: 管理者権限アカウントのみアクセス可（手動でFirebaseから権限付与）

- **ユーザー管理**: 
  - 検索/絞り込み
  - 表示項目: 登録日時、最終ログイン、課金状況
  - アカウント停止機能（確認ダイアログ表示）
  - 停止されたユーザーは「アカウント停止」画面のみ表示され、他の機能は利用不可
  - ユーザーの学習データや投稿履歴の閲覧機能なし
  - ポイントやランキングの手動調整機能なし

- **通報管理**: 
  - 通報一覧（通報者、被通報者、メッセージ内容を表示）
  - 対応ステータス（未対応/対応済み）の2種類のみ
  - 実行可能なアクション（アクション実行時に自動的に対応済みになる）:
    - メッセージ削除
    - アカウント停止

- **広告/お知らせ管理**:
  - 広告の作成（画像アップロード、タイトル、リンクURL、表示順、有効/無効）
  - 広告の編集・削除
  - プレビュー機能

- **追加予定**: 運用ダッシュボード（統計、MAU、売上）

### **3.9 将来機能（検討中）**

- 景品送付フロー（物流）
- より高度な分析レポート（Pro限定）

## **5. 学習セッションの詳細ルール**

### **5.1 日付境界の定義**

- **通常の日付**: カレンダー上の日付ではなく、**学習開始時刻を基準**とする
- **例**: 起床時間が6:00に設定されている場合
  - 1月1日 23:50に学習開始 → 1月2日 23:00に学習終了（23時間10分）
  - → **1月1日の学習として記録**
  - → 学習日は**1月1日**としてカウント
  - → 翌日（1月2日）6:00以降に新たに学習開始した場合、それが1月2日の学習となる

### **5.2 起床成功の判定**

- **判定条件**: 設定した起床時間**より前**に学習を開始した場合、「起床成功」とカウント
- **例**: 起床時間が6:00の場合
  - 5:30に学習開始 → 起床成功（+10点）
  - 6:00に学習開始 → 起床成功ではない
  - 6:30に学習開始 → 起床成功ではない
- **回数制限**: その日（学習開始時刻基準）において1回のみカウント

### **5.3 学習実施の判定**

- **判定条件**: 「学習開始」→「学習終了」の流れが完了した場合、「学習実施1日」とカウント（+5.5点）
- **回数制限**: その日（学習開始時刻基準）において1回のみカウント
- **最低学習時間**: 制限なし（1分でも学習終了すれば1日とカウント）

### **5.4 ストリーク（連続日数）の判定**

- **継続条件**: 設定した学習曜日に学習を実施すればストリーク継続
- **例**: 月・水・金を学習曜日に設定している場合
  - 火曜日に学習しなくてもストリーク継続
  - 月曜日に学習しなかった場合、ストリークはリセット（猶予日なし）
- **計算タイミング**: リアルタイム計算または日次バッチ（実装しやすい方を選択）
- **タイムゾーン**: 日本時間（JST）

## **6. UIガイドライン（抜粋）**

- 375px幅ベース（iPhone標準）
- グリッド: 12カラム / 8px間隔
- フォント: Noto Sans JP（タイトル600 / 本文400）
- アクセントはCTA・選択状態のみに限定
- メッセージや数値は一貫性のあるダミーデータを使用
- 情報密度を抑えたミニマルレイアウト
